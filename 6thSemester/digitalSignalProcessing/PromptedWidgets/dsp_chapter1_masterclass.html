Core Concepts — Deep + Intuitive

1. What is a Signal?

Definition: A signal is any physical quantity that carries information and varies as a function of one or more independent variables such as time, space, or frequency.
s = f(variable) Examples: s(t), I(x,y), I(x,y,t), s(t) = [s₁(t), s₂(t), s₃(t)]ᵀ

Intuition: Think of a signal as a "story" told by numbers. A temperature record every hour tells the story of how hot or cold it was throughout the day. A music file is a story of air pressure over time.

Key properties: Carries information · Can be measured, recorded, reproduced · Can be processed to extract/enhance meaning

2. Signal Dimensions & Types

1D Signal
s(t) — depends on time only

Examples: audio, ECG, stock prices

Multidimensional
I(x,y) — depends on x and y

Examples: images (2D), video (3D)

Real-valued
s(t) = A sin(3πt)

Takes only real number values

Complex-valued
s(t) = Ae^(jωt)

Used in communications/modulation

Multichannel vs Multidimensional (common confusion):
• Multichannel: multiple signals grouped as a vector → s(t) = [s₁(t), s₂(t), s₃(t)]ᵀ. Example: 3-lead ECG.
• Multidimensional: one signal depending on multiple variables. Example: I(x,y) is one signal depending on two variables.
• Color video I(x,y,t) is BOTH: multichannel (RGB = 3 channels) AND multidimensional (x, y, t).

3. Continuous-Time vs Discrete-Time ← Most fundamental distinction

Continuous-Time (CT)

Defined at every instant t ∈ ℝ. No gaps. Like drawing a curve without lifting your pen.

Notation: x(t) ← round brackets! t ∈ ℝ (all real numbers) x(t) = cos(2πt)

Examples: microphone voltage, radio waves, temperature sensor readings

Discrete-Time (DT)

Defined only at integer indices n ∈ ℤ. Like a list of measurements taken at equal time intervals.

Notation: x[n] ← square brackets! n ∈ ℤ (integers only) x[n] = cos(2πn/N)

Examples: digital audio, stock prices (daily closing), sampled sensor data

⚠️ Notation is tested in exams! Round brackets (t) = continuous-time. Square brackets [n] = discrete-time. Never write x(n) for a DT signal.
Stem plot for DT signals: Drawn as vertical lines (stems) at each integer n. Height of stem = x[n].
Real time conversion: t = n × Ts = n / fs
If fs = 8000 Hz and n = 160 → t = 160/8000 = 20 ms

4. Continuous-Valued vs Discrete-Valued (Quantization)

Continuous-Valued

Amplitude can be ANY real number in a range. Infinite precision.

x[n] ∈ ℝ e.g., 0.731, -1.234, 0.00001
Discrete-Valued

Amplitude from a finite set of levels only. Due to quantization (ADC).

x[n] ∈ {L₁, L₂, ..., L_{2^B}} B-bit ADC → 2^B levels 16-bit: 2^16 = 65,536 levels
Why discrete-valued? Computers store numbers in binary bits. A B-bit ADC divides the amplitude range into 2ᴮ equal steps (quantization). The smaller each step, the better the quality — but more bits = more storage.

6. Deterministic vs Random Signals

Deterministic

Fully described by a mathematical formula. Future values are perfectly predictable. Zero uncertainty.

x(t) = sin(t) x(t) = e^(-αt) u(t) x(t) = A cos(2πf₀t + φ)
Random (Stochastic)

No exact formula. Cannot be precisely predicted. Analyzed using probability and statistics.

x(t) = thermal noise x(t) = speech signal x(t) = seismic activity
Insight: Even though random signals are unpredictable in exact value, different random signals can share the same statistical properties (mean, variance, power spectral density). We use probability theory to study their behavior. Different realizations of noise look different but follow the same statistical distribution.

7. What is a System?

Definition: A system is any process or device that transforms an input signal into an output signal according to a defined rule or physical law.
y(t) = H{x(t)} where H = system operator

Convolution filter:y[n] = Σ h[k] x[n-k]

8. Basic Signal Operations — The Four Transformations

A
Amplitude Scaling: y(t) = A · x(t)

Multiplies height of the signal. Doesn't change shape or timing, only the "tallness."

  • A > 1: amplification (taller)
  • 0 < A < 1: attenuation (shorter)
  • A < 0: flip upside down AND scale
B
Time Shifting: y(t) = x(t − t₀)

Moves the signal left or right in time. Shape stays identical.

  • t₀ > 0: shift RIGHT (delayed — happens later)
  • t₀ < 0: shift LEFT (advanced — happens earlier)
⚠️ Memory trick: To find where a feature at t=0 moves, solve: t − t₀ = 0 → t = t₀. So x(t−2) moves features to t=+2 (rightward).
C
Time Scaling: y(t) = x(at)

Stretches or compresses the signal along the time axis.

  • |a| > 1: signal compresses (plays faster, shorter duration)
  • |a| < 1: signal expands (plays slower, longer duration)
  • New period = Old period / |a|
D
Time Reversal (Folding): y(t) = x(−t)

Flips the signal horizontally around the vertical axis (t=0). Like playing a recording backwards.

Feature originally at t=t₁ moves to t=−t₁.

🧠 Combined operations: y(t) = x(at + b)
Step 1: Factor out 'a' → x(a(t + b/a))
Step 2: Shift by −b/a (left if b/a > 0, right if b/a < 0)
Step 3: Scale by a (compress if |a|>1, expand if |a|<1)
Step 4: If a < 0, also reverse in time
Step 5: Apply amplitude scaling A separately
Always shift BEFORE scaling!

Worked Examples — Step by Step

Example 1 — Classify a signal completely

Problem: A digital audio file stores music at 44,100 Hz with 16-bit depth. Classify this signal fully.
1
Time axis: Samples taken every 1/44100 ≈ 22.7 µs → only exists at discrete instants → Discrete-Time. Notation: x[n].
2
Amplitude axis: 16-bit depth → 2¹⁶ = 65,536 levels → amplitude from a finite set → Discrete-Valued.
3
Combined: DT + DV = Digital Signal. Can be stored on a hard drive. ✓
4
Dimension: Depends only on time index n → 1D signal.
5
Predictability: A specific recording plays identically every time → Deterministic.
✅ Final Answer: 1D, Digital (DT + DV), Deterministic. 65,536 amplitude levels, sampled at 44.1 kHz.

Example 2 — Time shifting

Problem: Given x(t) = u(t) (unit step: 0 for t<0, 1 for t≥0). Find and describe y(t) = x(t − 3).
1
Identify operation: y(t) = x(t − 3). This is a time shift with t₀ = +3.
2
Direction: t₀ = +3 > 0 → signal shifts RIGHT by 3 units (delayed by 3 seconds).
3
Where does the step happen? Originally at t=0. Solving: t−3=0 → t=3. Step now occurs at t=3.
4
Result: y(t) = 0 for t < 3, and y(t) = 1 for t ≥ 3.
✅ Intuition: The signal does exactly the same thing, just 3 seconds later. Like pressing play at t=3 instead of t=0.

Example 3 — Time scaling

Problem: Given x(t) = sin(2πt), period T=1s. Find y(t) = x(2t) and z(t) = x(t/2).
1
y(t) = x(2t) = sin(2π·2t) = sin(4πt):
a = 2 > 1 → compress in time. New period = T/|a| = 1/2 = 0.5 s. Signal plays FASTER. Two full cycles in 1 second instead of one.
2
z(t) = x(t/2) = sin(2π·t/2) = sin(πt):
a = 0.5 < 1 → expand in time. New period = T/|a| = 1/0.5 = 2 s. Signal plays SLOWER. Half a cycle in 1 second.
✅ Rule to remember: Multiply argument by a > 1 → compress (faster, shorter period). Divide argument (a < 1) → expand (slower, longer period). New period = T₀ / |a|.

Example 4 — Time reversal

Problem: Given x(t) = t for 0 ≤ t ≤ 2, zero elsewhere (a ramp). Find y(t) = x(−t).
1
Original: x(t) is nonzero for t ∈ [0, 2]. It's a ramp going from x(0)=0 to x(2)=2.
2
Find new domain: x(−t) is nonzero when −t ∈ [0, 2], i.e., 0 ≤ −t ≤ 2, i.e., −2 ≤ t ≤ 0.
3
Find new values: y(t) = x(−t) = −t for −2 ≤ t ≤ 0.
4
Check key points: y(0) = x(0) = 0 ✓. y(−2) = x(2) = 2 ✓. The ramp now goes from 2 down to 0, on the LEFT side of the axis.
✅ Reversal flips the signal around t=0. Whatever was on the right side (positive t) appears mirrored on the left side (negative t).

Example 5 — Combined operations (exam-level)

Problem: Describe y(t) = x(2t + 4) in terms of transformations of x(t). Apply them in correct order.
1
Factor out the scale: y(t) = x(2t + 4) = x(2(t + 2)). Now we see: scale a=2, shift = −2 (i.e., shift left by 2).
2
Step 1 — Shift: Replace x(t) with x(t + 2). This shifts the signal LEFT by 2 units.
3
Step 2 — Scale: Replace t with 2t. Since a=2 > 1, compress by factor 2 (makes it faster/narrower).
4
Verify with boundary tracking: If x(t) is nonzero for t ∈ [0, 4], find where y(t) is nonzero.
Set 2t + 4 = 0 → t = −2. Set 2t + 4 = 4 → t = 0. So y(t) is nonzero for t ∈ [−2, 0]. Width: 2 (compressed from 4 by factor 2). ✓
⚠️ Common mistake: Doing scale BEFORE shift gives the wrong answer. Always shift first (after factoring), then scale.

Example 6 — Reading a stem plot & ADC calculation

Problem: A speech signal is sampled at fs = 8000 Hz with a 12-bit ADC. (a) How many amplitude levels? (b) What real time is sample n=400? (c) What sample index is t = 50 ms?
a
Amplitude levels: B = 12 bits → 2¹² = 4,096 levels.
b
Real time at n=400: t = n/fs = 400/8000 = 0.05 s = 50 ms.
c
Sample index at t=50ms: n = t × fs = 0.050 × 8000 = 400.
✅ Note: Parts (b) and (c) give the same answer — they are inverse operations of each other! t = n/fs ↔ n = t × fs.

Common Mistakes & How to Avoid Them

Mistake 1 — "Discrete-Time = Digital"

❌ Wrong: "A sampled signal is a digital signal."
✅ Correct: A DT signal has a discrete time axis, but amplitude may still be continuous (any real number). Digital requires BOTH discrete time AND discrete values. A DT signal only becomes digital after quantization by an ADC.

Example: Audio sampled at 44.1 kHz in a floating-point buffer (before quantization) is DT but NOT digital. After 16-bit quantization, it becomes digital.

Mistake 2 — Time shift direction confusion

❌ Wrong: "x(t − 2) means the signal moves to the LEFT."
✅ Correct: x(t − 2) shifts RIGHT (delayed by 2). x(t + 2) shifts LEFT (advanced by 2).
Foolproof method: To find where a feature at t=t₁ moves, solve: (t − t₀) = t₁ → t = t₁ + t₀. So if t₀=+2, the feature that was at t₁ moves to t₁+2 (rightward). Never guess direction intuitively — always solve algebraically.

Mistake 3 — Wrong order of combined operations

❌ Wrong order for x(2t + 4): "Scale by 2 first (compress), then shift right by 4."
This gives x(2(t−4)) = x(2t−8) ≠ x(2t+4). Wrong!
✅ Correct: Factor first: x(2t + 4) = x(2(t + 2)). Then: (1) shift LEFT by 2, (2) compress by 2. The two approaches give different results because scaling affects where the shift lands.

Mistake 4 — Notation errors

❌ Wrong: Writing x(n) for a discrete-time signal (round brackets with n).
✅ Correct: x[n] with SQUARE brackets for DT. x(t) with ROUND brackets for CT. This convention is universal in DSP and is marked in exams.

Mistake 5 — "Analog = Continuous-Time only"

❌ Wrong: "An analog signal just means the time is continuous."
✅ Correct: Analog = Continuous-Time AND Continuous-Valued (both axes are continuous). A signal with continuous time but discrete values is "quantized analog," not "analog."

Mistake 6 — Multichannel vs Multidimensional

❌ Wrong: "RGB image is a 3-dimensional signal because it has 3 colors."
✅ Correct: RGB image is a multichannel signal (3 channels) that is 2-dimensional (depends on x and y). Color video I(x,y,t) is multichannel (3 channels) AND 3-dimensional (x, y, t). These are orthogonal properties.

Mistake 7 — Forgetting to check boundaries after transformation

❌ Wrong: Describing the shape of a transformed signal correctly but stating the wrong domain (time interval where it exists).
✅ Correct: Always track where the signal boundaries move. Take each endpoint of the original domain, substitute it into the argument, and solve for the new t values. E.g., if original is nonzero for t ∈ [a,b] and y(t)=x(2t+4), find: 2t+4=a → t=(a−4)/2 and 2t+4=b → t=(b−4)/2.

Practice Problems — Easy to Hard

Attempt each problem yourself first. Then click "Show Answer" to verify.

★ Easy — Concepts & Classification

Q1: A thermostat reads temperature continuously but outputs only {18°, 19°, 20°, 21°, 22°}C. What type of signal is this?
Easy
Answer: Continuous-Time, Discrete-Valued (Quantized Analog).

• Time: The thermostat reads at all times → t ∈ ℝ → Continuous-Time.
• Amplitude: Only 5 fixed values {18,19,20,21,22} → Discrete-Valued.
• This is NOT digital (digital needs discrete time too). NOT analog (analog needs continuous values too).
• Classification: Quantized Analog — top right cell of the 2×2 table.
Q2: Is x(t) = 3e^(−2t)u(t) a deterministic or random signal? Evaluate it at t=0.5.
Easy
Answer: Deterministic.

It has an exact mathematical formula. Every future value is perfectly calculable.

At t = 0.5: x(0.5) = 3e^(−2×0.5)u(0.5) = 3e^(−1) × 1 ≈ 3 × 0.368 = 1.104.

A random signal would not have a formula that gives you this precision.
Q3: Identify what type of signal can be stored on a computer and explain why.
Easy
Answer: Only Digital signals (DT + DV) can be stored on a computer.

Reason 1 (Discrete-Time): A computer can only store a finite number of samples. CT signals exist at infinitely many time points — impossible to store all of them.
Reason 2 (Discrete-Valued): A computer stores numbers in binary (bits). It can only represent a finite set of amplitude values (2^B levels for B bits). Continuous amplitudes would require infinite precision.
Q4: Classify a grayscale JPEG image and a 3-axis accelerometer reading as signals (give all applicable labels).
Easy
Grayscale JPEG: 2D (depends on x,y position), Digital (discrete pixel positions + 8-bit values = 256 gray levels), Scalar (one brightness value per pixel), Deterministic (same image always).

3-axis accelerometer: CT (reads continuously, t∈ℝ), CV (voltage is continuous), Analog, Multichannel (3 channels: x-axis, y-axis, z-axis acceleration), Random (motion is unpredictable).

★★ Medium — Transformations & Calculations

Q5: Given x(t) = rectangular pulse (1 for 0≤t≤4, 0 elsewhere). Describe y(t) = x(t/2 − 1) fully (domain + values).
Medium
Step 1 — Factor: x(t/2 − 1) = x((1/2)(t − 2)). So a = 1/2, shift = +2 (right).

Step 2 — Find new domain: x(t) is 1 for 0 ≤ t ≤ 4. We need: 0 ≤ t/2 − 1 ≤ 4. Solving: 1 ≤ t/2 ≤ 5 → 2 ≤ t ≤ 10.

Step 3 — Result: y(t) = 1 for 2 ≤ t ≤ 10, and 0 elsewhere. Width = 8 (original width 4, expanded by factor 1/a = 2).

Check: Left edge: t/2−1=0 → t=2 ✓. Right edge: t/2−1=4 → t=10 ✓. Width doubled because |a|=1/2 < 1 → expansion by 1/|a|=2. ✓
Q6: A signal is sampled at fs = 44,100 Hz with a 24-bit ADC. (a) How many quantization levels? (b) What is sample index n for t = 5.5 ms?
Medium
(a) Quantization levels: B = 24 bits → 2²⁴ = 16,777,216 levels (about 16.8 million). This is professional/studio audio quality, far better than 16-bit (65,536 levels).

(b) Sample index at t = 5.5 ms:
n = t × fs = 0.0055 × 44100 = 242.55 ≈ 242 (round to nearest integer).

Ts = 1/44100 ≈ 22.68 µs per sample. So 5.5 ms ÷ 22.68 µs ≈ 242 samples.
Q7: Given x(t) = u(t) − u(t−3) (pulse from 0 to 3). Sketch and describe y(t) = −x(−t + 6).
Medium
Step 1 — Identify operations in y(t) = −1 · x(−t + 6) = −1 · x(−(t − 6)):
• Amplitude: A = −1 (flip upside down)
• a = −1 (time reversal)
• shift: factor gives x(−(t−6)) → shift right by 6

Step 2 — Find domain: x(t) is 1 for 0 ≤ t ≤ 3. Need: 0 ≤ −t+6 ≤ 3 → −6 ≤ −t ≤ −3 → 3 ≤ t ≤ 6.

Step 3 — Values: y(t) = −1 × 1 = −1 for 3 ≤ t ≤ 6, zero elsewhere.

Describe in words: Original pulse (height +1, domain [0,3]) was reversed (flipped left-right → domain [−3,0], still height +1), then shifted right by 6 (domain [3,6], still height +1), then flipped amplitude (height −1). Result: downward pulse of amplitude −1 from t=3 to t=6.

★★★ Hard — Exam Level

Q8: Given x(t) = t² for −1 ≤ t ≤ 2, zero elsewhere. Find y(t) = 2·x(−t/3 + 1). State domain, formula, and all transformations applied.
Hard
Step 1 — Parse and factor:
y(t) = 2 · x(−t/3 + 1) = 2 · x(−(1/3)(t − 3))
So: amplitude A=2, scale a=−1/3 (|a|=1/3 → expand ×3, and negative → reversal), shift = +3 (right).

Step 2 — Find new domain by solving for original argument range:
x(u) is nonzero for −1 ≤ u ≤ 2 where u = −t/3 + 1.
Left boundary: −t/3 + 1 = −1 → −t/3 = −2 → t = 6.
Right boundary: −t/3 + 1 = 2 → −t/3 = 1 → t = −3.
Since the signal is reversed (a < 0), the boundaries swap: t ∈ [−3, 6].

Step 3 — Formula within domain:
y(t) = 2·x(−t/3+1) = 2·(−t/3+1)² for −3 ≤ t ≤ 6, zero elsewhere.

Step 4 — Summary of transformations applied to x(t):
1. Time reverse: x(−t) — flip around t=0
2. Expand by 3: x(−t/3) — stretch by factor 3
3. Shift right by 3: x(−(t−3)/3) = x(−t/3+1) — move to the right
4. Amplitude scale by 2: 2·x(−t/3+1) — double the height

Width of original: 2−(−1)=3 → Width of transformed: 3 × (1/|a|) = 3 × 3 = 9. Check: 6−(−3)=9. ✓
Q9: True or False with explanation: (a) Every discrete-time signal is a digital signal. (b) x[n] = cos(πn/4) is both DT and deterministic. (c) Multichannel means multidimensional. (d) A 24-bit ADC is always better than a 16-bit ADC.
Hard
(a) False. DT means discrete time axis only. Digital requires BOTH discrete time AND discrete values. A DT signal with continuous-valued amplitude (e.g., computed in floating-point) is DT but not digital.

(b) True. x[n] uses square brackets → DT. It has a precise formula cos(πn/4) → deterministic. At n=4: x[4] = cos(π) = −1. Predictable at any n.

(c) False. Multichannel = multiple signals in a vector (e.g., ECG 3-lead). Multidimensional = one signal depending on multiple variables (e.g., image I(x,y)). They are independent concepts. A signal can be one, both, or neither.

(d) Not always. 24-bit gives 2²⁴ = 16.7M levels vs 16-bit's 65,536 levels — 24-bit has much finer amplitude resolution, which is better in most cases. However, it requires more storage and processing power. For some applications (e.g., basic telephony), 16-bit is more than sufficient. "Better" depends on the application requirements.

Exam Strategy — How to Score Maximum Marks

Common exam question patterns

1
Classification questions
Given a real-world scenario or formula, classify the signal. These are the most frequent. Always tick off the checklist mentally: CT/DT? CV/DV? Deterministic/Random? 1D/Multi? Multichannel?
2
Transformation questions (sketch or describe)
Given x(t) and y(t) = expression, describe or sketch y(t). Use the factor method. Track boundaries. Verify with spot-checks.
3
ADC / sampling calculations
levels = 2^B, t = n/fs, n = t×fs. Short calculations, easy marks.
4
True/False or MCQ on definitions
Know the 2×2 table. Know notation (round vs square brackets). Know that "digital" = DT AND DV, not just one.
5
System identification
Given y(t) = H{x(t)}, identify what operation H performs (delay, amplification, integration, etc.)

Problem-solving checklist for transformation questions

For y(t) = A · x(at + b):

□ Step 1: Factor → y(t) = A · x(a(t + b/a))
□ Step 2: Identify A (amplitude), a (scale/direction), b/a (shift amount)
□ Step 3: Note if a < 0 (reversal will happen)
□ Step 4: Find new domain by substituting original boundaries into the argument
□ Step 5: Write the formula within the new domain
□ Step 6: Verify 2-3 specific points (plug t value, check output matches expected)
For classification questions:

□ What type is the independent variable (time, space)?
□ Is it defined at every instant? → CT. At integer indices only? → DT.
□ Can amplitude be any real number? → CV. From a finite set? → DV.
□ DT + DV = Digital (the only kind computers can store).
□ Is there an exact formula? → Deterministic. No formula, unpredictable? → Random.
□ One variable (time) → 1D. Multiple variables → Multidimensional.
□ One value per point → Scalar. Multiple values per point → Multichannel.

SignalPhysical quantity carrying information: s = f(variable). Can be measured, recorded, processed.
CT signal x(t)Defined for all t ∈ ℝ. Round brackets. Smooth curve. From real-world sensors.
DT signal x[n]Defined only at integers n ∈ ℤ. Square brackets. Stem plot. From sampling.
AnalogCT + CV. Both axes continuous. e.g., microphone voltage.
DigitalDT + DV. Both axes discrete. Only type computers can store.
DeterministicHas exact mathematical formula. Perfectly predictable. e.g., sin(t), e^(-αt).
RandomNo formula. Unpredictable. Use statistics. e.g., noise, speech, seismic.
MultichannelMultiple signals as vector: s(t) = [s₁,s₂,s₃]ᵀ. e.g., ECG 3-lead, RGB.
MultidimensionalSignal depends on multiple variables. e.g., I(x,y) image, I(x,y,t) video.
SystemTransforms input to output: y(t) = H{x(t)}. e.g., amplifier, filter, delay.
ADC levelsN = 2^B for B-bit ADC. 16-bit = 65,536. 24-bit = 16,777,216.
Sampling timingt = n/fs = n·Ts. Inverse: n = t × fs. Both convert between sample index and real time.
Sinusoidx(t) = A cos(2πf₀t + φ). Period T₀ = 1/f₀. Amplitude A. Phase φ.

Signal Operations Quick Reference

Amplitude scaley(t) = A·x(t). Stretches/compresses vertically. A>1: amplify. 0<A<1: attenuate. A<0: flip+scale.
Time shifty(t) = x(t−t₀). t₀>0: shift RIGHT (delay). t₀<0: shift LEFT (advance). Shape unchanged.
Time scaley(t) = x(at). |a|>1: compress/faster. |a|<1: expand/slower. New period = T₀/|a|.
Time reversaly(t) = x(−t). Flip around t=0 axis. Feature at t₁ moves to −t₁.
Combinedy(t) = x(at+b): Factor → x(a(t+b/a)). Order: (1) shift by −b/a, (2) scale by |a|, (3) if a<0 reverse. Always shift BEFORE scale.

Analog vs Digital Quick Comparison

FeatureAnalogDigital
Signal formContinuous smooth valuesDiscrete binary values (bits)
Noise immunityLow — noise accumulatesHigh — error correction possible
StorageDegrades (tape, film)Lossless (HDD, cloud)
FlexibilityFixed hardwareReprogrammable software
PrecisionLimited by componentsExactly set by bit depth
SpeedVery fastNeeds fast ADC clock

Neither is universally better. Modern systems combine both — analog for sensing the physical world, digital for storage, transmission, and processing.

Key Formulas

Sinusoid: x(t) = A cos(2πf₀t + φ) T₀ = 1/f₀ DT sampling: t = n·Ts = n/fs n = t × fs ADC: N = 2^B levels (B = bit depth) System: y(t) = H{x(t)} Color video: I(x,y,t) = [Iᴿ, Iᴳ, Iᴮ]ᵀ ← multichannel + 3D Quantization: Δ = (x_max − x_min) / 2^B (step size)

Mental Model — Signal Universe Map

Every signal can be described by 6 independent properties: 1. Time axis: Continuous-Time x(t) vs Discrete-Time x[n] 2. Amplitude axis: Continuous-Value vs Discrete-Value → CT + CV = Analog DT + DV = Digital ⭐ (only type storable on PC) 3. Predictability: Deterministic (formula) vs Random (statistics) 4. Dimensions: 1D s(t) vs 2D I(x,y) vs 3D I(x,y,t) vs ... 5. Channels: Scalar s(t) vs Vector (multichannel) s(t)=[s₁,s₂,s₃]ᵀ 6. Value type: Real s(t)∈ℝ vs Complex s(t)=a+jb
🧠 Golden rule: When you see any signal in an exam — before doing anything else — classify it on ALL 6 properties above. This prevents mistakes and earns classification marks automatically.
