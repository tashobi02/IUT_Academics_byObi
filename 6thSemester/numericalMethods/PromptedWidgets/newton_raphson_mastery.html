Newton-Raphson
Method

From intuition to mastery — everything you need to solve problems fluently and explain the method confidently in any exam.

xi+1 = xi − f(xi) / f′(xi)
Section 01

Core Intuition

🎯 What problem are we solving?

We want to find the root of an equation — the value of x where f(x) = 0. This means: where does the curve cross the x-axis?

For example, if you need to solve x³ = 20, you rewrite it as f(x) = x³ − 20 = 0 and ask: what is x?

💡 Big Picture
Newton-Raphson is an open method — it needs only one initial guess (unlike bisection which needs two). It doesn't guarantee convergence, but when it converges, it does so blazingly fast.

📐 Geometric Intuition — The Tangent Line Idea

Here's the core idea, step by step:

  1. You make a guess xi about where the root might be.
  2. You plot the point (xi, f(xi)) on the curve.
  3. You draw the tangent line to the curve at that point. (A tangent is a straight line that "just touches" the curve and has the same slope as the curve at that point.)
  4. You see where this tangent line crosses the x-axis — call it xi+1.
  5. That crossing point is your improved, better guess for the root!
  6. You repeat using xi+1 as your new starting point — each time getting closer.
💡 Mental Image
Imagine standing on a hill in fog — you can't see the bottom (the root), but you can feel the slope beneath your feet (the derivative). You step in the direction the slope points. Each step lands you closer to the valley bottom.

🤔 Why does it work?

Near any smooth point on a curve, the tangent line is a very good local approximation of the curve. If your guess is already somewhat close to the root, the tangent line's x-intercept will be much closer to the root than your original guess was. This is the magic of Newton-Raphson — it exploits local linearity to make huge leaps in accuracy.

⚠️ Key Caveat
This method is an open method — convergence is NOT guaranteed. If your initial guess is far from the root, or near a flat spot (inflection point / local extremum), the method may fail. When it works though, it is extremely powerful.
Section 02

Mathematical Derivation

Method 1: From Slope (Geometric — Your Lecture's Primary Approach)

We exploit the definition of slope. The tangent line at (xi, f(xi)) has slope equal to the derivative f′(xi), and it passes through the point and the x-axis.

①
Write the slope of the tangent at xi:
f′(xᵢ) = tan θ

The derivative IS the slope. The angle θ is the angle the tangent makes with the x-axis.

②
Express the slope using rise-over-run between (xi, f(xi)) and (xi+1, 0):
f′(xᵢ) = (f(xᵢ) − 0) / (xᵢ − xᵢ₊₁)

The tangent starts at height f(xᵢ) and ends at the x-axis (height = 0). The horizontal run is xᵢ − xᵢ₊₁. Note: denominator is xᵢ − xᵢ₊₁, not xᵢ₊₁ − xᵢ, to keep the slope positive when the curve slopes downward toward the root.

③
Multiply both sides by (xi − xi+1):
f′(xᵢ) · (xᵢ − xᵢ₊₁) = f(xᵢ)

Simple cross-multiplication.

④
Solve for xi+1:
xᵢ − xᵢ₊₁ = f(xᵢ) / f′(xᵢ) xᵢ₊₁ = xᵢ − f(xᵢ) / f′(xᵢ) ✓

Rearrange: subtract xᵢ from both sides, then multiply by −1.

✅ Result
This is the Newton-Raphson formula. We derived it purely from the geometric meaning of slope.

Method 2: From Taylor Series (Your Lecture's Second Approach)

The Taylor series expands a function around a known point:

f(x + h) = f(x) + f′(x)·h + f″(x)·h²/2! + f‴(x)·h³/3! + …
①
Expand f(xi+1) around xi:
f(xᵢ₊₁) = f(xᵢ) + f′(xᵢ)(xᵢ₊₁−xᵢ) + f″(xᵢ)(xᵢ₊₁−xᵢ)²/2! + …

This is just the Taylor series with h = (xᵢ₊₁ − xᵢ).

②
We WANT xi+1 to be the root, so set f(xi+1) = 0:
0 = f(xᵢ) + f′(xᵢ)(xᵢ₊₁−xᵢ) + f″(xᵢ)(xᵢ₊₁−xᵢ)²/2! + …

This is the key assumption — we're hoping xᵢ₊₁ is the root.

③
Keep only the first two terms (truncate higher-order terms):
0 ≈ f(xᵢ) + f′(xᵢ)(xᵢ₊₁ − xᵢ)

This is a first-order (linear) approximation. The higher-order terms are small if xᵢ₊₁ is close to xᵢ.

④
Solve for xi+1:
f′(xᵢ)(xᵢ₊₁ − xᵢ) ≈ −f(xᵢ) xᵢ₊₁ ≈ xᵢ − f(xᵢ) / f′(xᵢ) ✓

Divide both sides by f′(xᵢ), then add xᵢ. Same formula!

✅ Both methods agree
The geometric method and the Taylor series method both give exactly the same formula. This confirms we're on solid mathematical ground. The ≈ symbol appears because we truncated the Taylor series — introducing a small error that shrinks with each iteration.
Section 03

Algorithm & Formula

The Newton-Raphson Formula

xᵢ₊₁ = xᵢ − f(xᵢ) / f′(xᵢ) // Next guess = Current guess − (Function value) / (Derivative value)

Error Formula

|εₐ| = |( xᵢ₊₁ − xᵢ ) / xᵢ₊₁| × 100% // Absolute Relative Approximate Error (stop when this is small enough)
💡 Significant Digits Rule
Your answer has at least m significant digits correct if |εₐ| ≤ 0.5 × 102−m %. Example: for m=2, need |εₐ| ≤ 0.5% = 5×10⁻¹%. As a rough guide: 1 sig fig → |εₐ| ≤ 5%, 2 sig figs → ≤ 0.5%, 3 sig figs → ≤ 0.05%.

Step-by-Step Algorithm (from your lecture)

  1. Rewrite the equation in the form f(x) = 0. (Move everything to one side.)
  2. Differentiate symbolically to get f′(x). Do this ONCE before any iteration.
  3. Choose an initial guess x₀. (Often given in the problem. If not, a rough estimate works.)
  4. Apply the formula: xi+1 = xi − f(xi)/f′(xi)
  5. Compute the absolute relative approximate error |εₐ|.
  6. Check stopping criteria: If |εₐ| ≤ εs (given tolerance), stop. Otherwise, set xi = xi+1 and go back to Step 4.
  7. Also check: if iteration count exceeds maximum allowed iterations, stop and report failure.
⚠️ Watch Out
Always compute f′(x) SYMBOLICALLY (analytically) before starting. Never approximate it numerically unless specifically asked. And always check that f′(xᵢ) ≠ 0 before dividing!

f(x) = x³ − 20 f′(x) = 3x² x₀ = 3

Section 05

Convergence & When It Fails

✅ When Newton-Raphson Converges Fast

  • Your initial guess x₀ is close to the actual root.
  • The function is smooth and well-behaved near the root (no wiggles).
  • The derivative f′(x) is large (steep slope) near the root — the tangent line shoots straight to the x-axis.
  • The function has simple, isolated roots.

📊 Convergence Rate: Quadratic

Newton-Raphson has quadratic convergence. This means the number of correct significant digits approximately doubles with each iteration. In your lecture example:

Iter 1
0 sig figs
Iter 2
1 sig fig
Iter 3
3 sig figs ✓

❌ The 4 Failure Modes (from your lecture)

⚠️ Failure 1: Divergence at Inflection Points
If your current guess lands near an inflection point (where concavity changes — f″(x) = 0), the tangent is nearly flat and shoots the next guess far away. The method may diverge wildly or oscillate before eventually converging back.
⚠️ Failure 2: Division by Zero (f′(x) = 0)
If the derivative is zero at your guess — i.e., you land exactly at a local maximum or minimum — the tangent line is horizontal and never crosses the x-axis. Division by zero occurs! Example: f(x) = x³ − 0.03x² + 2.4×10⁻⁶ has f′(x) = 3x² − 0.06x = 0 at x = 0 and x = 0.02.
⚠️ Failure 3: Oscillation near Local Max/Min (No Real Root)
For functions like f(x) = x² + 2 (no real roots), the method oscillates endlessly between negative and positive x values around the minimum, never converging.
⚠️ Failure 4: Root Jumping
For oscillating functions with multiple roots, even if you start close to one root, the tangent line may send you flying to a completely different root far away. The method finds a root, but not necessarily the one you wanted.

🚨 Common Student Mistakes

  • Forgetting to subtract: Writing xi+1 = xi + f(xi)/f′(xi) instead of minus. Always minus!
  • Using f(xi) as the denominator instead of f′(xi). Very common mistake — always the derivative on the bottom!
  • Error formula denominator wrong: Using xi instead of xi+1 in the denominator of the error formula.
  • Not rewriting the equation as f(x) = 0 first. You must bring everything to one side before differentiating.
  • Rounding too early. Keep maximum decimal places during iteration, round only at the final answer.
  • Forgetting to differentiate f(x) correctly (e.g., differentiating x³ as 3x instead of 3x²).
Section 06

Exam Strategy

⚡ Speed Trick 1

Write the NR formula at the top of your answer sheet BEFORE you start. Then derive f and f′ symbolically ONCE and verify. Never re-derive in the middle of a table.

⚡ Speed Trick 2

Build your iteration table column by column, not row by row. Fill all f(xᵢ) values, then all f′(xᵢ), then all xᵢ₊₁. Reduces context-switching errors.

⚡ Speed Trick 3

For the error formula, always check: denominator = xNEW (the one you just calculated), not the old one. Mnemonics: "new below, difference on top."

⚡ Speed Trick 4

When you see the iteration values barely changing (e.g., 2.71467 → 2.71442), the error will be tiny. Trust the pattern and compute anyway.

⚡ Speed Trick 5

If asked "how many sig figs are correct?" use: m is the largest integer satisfying |εₐ| ≤ 0.5×102−m%. Shortcut: |εₐ| ≈ 0.0092% → m = 3.

⚡ Speed Trick 6

For square root questions (find √N), immediately set f(x) = x² − N, f′(x) = 2x. This is a classic exam pattern you should recognize in 3 seconds.

Common Exam Question Patterns

  1. "Solve [equation] using NR method with x₀ = [value]. Perform n iterations." → Straightforward. Set up table, run n iterations, report final value + errors.
  2. "Find the root with tolerance εs = [%]" → Run until |εₐ| ≤ εs, then stop.
  3. "Find the number of significant digits correct after each iteration." → Compute |εₐ| per iter, then find m from 0.5 × 102−m ≥ |εₐ|.
  4. "Derive the NR formula from Taylor series" → Memorize the 4-step Taylor series derivation. This is a high-value theory question.
  5. "What are the drawbacks of the NR method?" → List the 4 failure modes. Explain each with a function example.
  6. "Why does NR converge faster than Bisection?" → NR = quadratic convergence (digits double). Bisection = linear (one extra bit per iteration).

Anti-Error Checklist (Before Submitting)

✅ Final Check
  • Did you rewrite as f(x) = 0? ✓
  • Did you correctly differentiate f′(x)? ✓
  • Is the formula xi+1 = xi minus f/f′? ✓
  • Is the error denominator xi+1 (the new value)? ✓
  • Did you multiply error by 100 to get %? ✓
  • Significant digits: used 0.5 × 102−m % formula? ✓

Section 08

Deeper Understanding

🔗 Connection to Derivatives and Linear Approximation

Newton-Raphson is fundamentally a linear approximation method. At any point on a smooth curve, the tangent line is the best linear approximation. Newton-Raphson says: "Replace the curve with its tangent at the current guess, then solve the simpler linear equation."

More formally, the tangent line at (xi, f(xi)) is:

y = f(xᵢ) + f′(xᵢ)(x − xᵢ)

Setting y = 0 (finding where this line hits the x-axis) gives exactly:

0 = f(xᵢ) + f′(xᵢ)(x − xᵢ) → x = xᵢ − f(xᵢ)/f′(xᵢ)

This connects to the Taylor series: f(x) ≈ f(xi) + f′(xi)(x − xi) is the first-order Taylor approximation. NR is nothing more than solving this approximation for its zero.

⚡ Application: Fast Division (From Your Lecture)

Your lecture shows an incredible application: CPUs use Newton-Raphson to compute divisions (and square roots) without using actual division hardware! To compute 1/D:

f(x) = 1/x − D = 0 → root is x = 1/D f′(x) = −1/x² xᵢ₊₁ = xᵢ(2 − D·xᵢ) [NR formula, simplified]

This formula uses only multiplication and subtraction — no division! A hardware multiplier can perform this in roughly 9 clock cycles per iteration. With a lookup table for the initial guess, only 2 iterations are needed. This is how modern processors compute floating-point division at high speed.

🧠 The "Mini Quiz" from Your Lecture

💡 Piecewise Linear Function
Your lecture asks: for a piecewise linear function, how many iterations will NR need? The answer is exactly 1 iteration! Why? A piecewise linear function IS already made of straight lines. The tangent at any point on a line IS the line itself. So the tangent's x-intercept IS the exact root — found in one step.

🌊 Why Quadratic Convergence Is Mind-Blowing

Bisection halves the error every iteration. After 10 iterations you've got 10× more zeros in the error. Newton-Raphson squares the error. After 10 iterations (starting from 1 correct digit), you'd have 2¹⁰ = 1024 correct digits. This is why NR is the workhorse of numerical computation in science and engineering.

✅ Final Thought
Newton-Raphson is not just a numerical trick — it's a deep idea: replace a hard nonlinear problem with a sequence of easy linear problems. Each linear approximation is better than the last, and they converge on the truth faster than almost any other method. This same idea powers optimization algorithms (gradient descent), machine learning, and engineering design tools used worldwide.
